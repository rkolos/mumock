# NinjaTickets Admin Mockup

Мокап админ-панели для системы поддержки NinjaTickets, созданный на Next.js 14 с App Router.

## Технологии

- **Next.js 14** (App Router)
- **React 18**
- **Tailwind CSS**
- **Lucide React** (иконки)
- **TypeScript**

## Установка и запуск

```bash
# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev

# Собрать для production
npm run build

# Запустить production сервер
npm start
```

После запуска приложение будет доступно по адресу: http://localhost:3000

## Структура проекта

```
app/
  ├── layout.tsx          # Root layout
  ├── page.tsx            # Главная страница (список тикетов)
  └── tickets/
      └── [id]/
          └── page.tsx    # Страница деталей тикета

components/
  └── admin/
      ├── Sidebar.tsx     # Боковая панель навигации
      ├── Header.tsx      # Верхняя панель
      ├── TicketsList.tsx # Компонент списка тикетов
      └── TicketDetails.tsx # Компонент деталей тикета

data/
  └── tickets.ts          # Демо-данные тикетов
```

## Функциональность

### Главная страница (Список тикетов)

- Отображение всех тикетов в таблице
- Фильтрация по различным критериям (чипы)
- Переход к деталям тикета при клике на строку
- Адаптивный дизайн

### Страница деталей тикета

- Отображение основной информации о тикете
- Динамические поля в зависимости от категории:
  - **Financial**: Transaction ID (с пометкой ИИ)
  - **Technical**: Environment и Error Logs (с пометкой ИИ)
- Поля, заполненные ИИ, помечены иконкой робота (Bot)

### Навигация

- Sidebar с разделами Main и System
- Адаптивный sidebar (скрывается на экранах < 1024px)
- Профиль пользователя в нижней части sidebar

## Демо-данные

В проекте используются 4 демо-тикета:
1. Financial тикет с Transaction ID
2. Technical тикет с Environment и Error Logs
3. General тикет
4. Technical тикет с критическим приоритетом

## Развертывание на Vercel

1. Создайте аккаунт на Vercel
2. Подключите репозиторий
3. Vercel автоматически определит Next.js и настроит сборку
4. После деплоя приложение будет доступно по ссылке
