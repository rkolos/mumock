# Правила проверки перед коммитом

## Обязательный процесс проверки перед каждым коммитом:

1. **Проверка типов TypeScript** (обязательно):
   ```bash
   npm run type-check
   ```
   - Проверяет все TypeScript ошибки без создания файлов
   - Должна пройти без ошибок перед коммитом

2. **Проверка сборки** (обязательно для важных изменений):
   ```bash
   npm run build
   ```
   - Запускает ту же проверку, что и на сервере сборки
   - Проверяет компиляцию, типы и линтинг
   - Должна пройти успешно перед коммитом

3. **Полная проверка** (рекомендуется):
   ```bash
   npm run check
   ```
   - Запускает проверку типов и линтинг
   - Использовать перед каждым коммитом

4. **Линтинг** (опционально, если настроен):
   ```bash
   npm run lint
   ```

## Процесс перед коммитом:

ПЕРЕД КАЖДЫМ КОММИТОМ всегда выполнять:
1. `npm run type-check` - должна пройти без ошибок
2. `npm run build` - должна пройти успешно (особенно перед push в main/develop)
3. Только после успешной проверки - делать коммит и push

## Важно:
- Никогда не коммитить код с TypeScript ошибками
- Всегда проверять сборку перед push в основную ветку
- Если проверка не прошла - исправить ошибки перед коммитом
