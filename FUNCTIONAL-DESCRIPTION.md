# Функциональное описание проекта NinjaTickets Admin

Данный документ содержит полное функциональное описание всех экранов, компонентов и функций админ-панели системы поддержки NinjaTickets.

---

## 1. Тикеты (Tickets)

### 1.1. Список тикетов (`/` - главная страница)

**Назначение:** Просмотр и управление всеми тикетами системы.

**Компонент:** `components/admin/TicketsList/index.tsx`

#### Отображаемые столбцы таблицы:
- **Username** - имя пользователя
- **Channel** - канал связи
- **Category** - категория тикета
- **Assigned Users** - назначенные пользователи (через запятую, или "—" если нет)
- **Tags** - теги в виде чипов
- **Priority** - приоритет (low, medium, high, critical) с цветовой индикацией
- **Status** - статус тикета (open, in-progress, resolved, closed) с цветовой индикацией
- **Created At** - дата создания (сортируется по умолчанию)

#### Smart Views (доступны в подменю Sidebar):
1. **Your Inbox** (`?view=your_inbox`) - тикеты, назначенные текущему пользователю и не закрытые
2. **Mentions** (`?view=mentions`) - тикеты с упоминаниями текущего пользователя (поле `mentions`)
3. **Awaiting Reply** (`?view=awaiting_reply`) - тикеты, назначенные пользователю, где последнее сообщение от пользователя (`lastMessageAuthorId === 'user'`)
4. **Unassigned** (`?view=unassigned`) - неназначенные тикеты (пустой массив `assignedUsers`), не закрытые
5. **All Tickets** - все тикеты (без фильтрации)

#### Фильтры:
- **Source** - фильтр по источнику (Discord, Telegram, WhatsApp, Web, Email, API)
- **Status** - множественный выбор статусов
- **Priority** - множественный выбор приоритетов
- **Assigned Users** - множественный выбор назначенных пользователей
- **Tags** - множественный выбор тегов
- **Categories** - множественный выбор категорий
- **Date Range** - фильтр по дате создания (from/to)
- **Waiting Time** (QuickTimeFilters) - быстрые фильтры по времени ожидания:
  - `1h+` - более 1 часа ожидания
  - `6h+` - более 6 часов ожидания
  - `12h+` - более 12 часов ожидания
  - `24h+` - более 24 часов ожидания
  - `All` - все тикеты
- **Поиск** - поиск по полям: Username, Channel, Category, AI Title

#### Функции:
- Переход к деталям тикета при клике на строку
- Синхронизация всех фильтров с URL параметрами (сохранение состояния при обновлении страницы)
- Filter Chips (`TicketsFilterChips`) - отображение активных фильтров с возможностью удаления
- QuickTimeFilters (`QuickTimeFilters`) - быстрые переключатели фильтра по времени ожидания с подсчетом тикетов
- Фильтр-меню (`TicketsFilterDropdown`) - выпадающее меню для добавления фильтров
- Обновление списка (`RefreshCw` иконка)
- Адаптивный дизайн

### 1.2. Детали тикета (`/tickets/[id]`)

**Назначение:** Просмотр и управление конкретным тикетом, переписка с пользователем.

**Компонент:** `components/admin/TicketView/index.tsx`

#### Отображаемые разделы:

**Левая панель - Основной контент:**
- **Заголовок** - AI Title (если есть) или стандартный заголовок с кнопкой "Назад"
- **Сообщения** - переписка с пользователем:
  - Аватар автора (инициалиалы или системный значок)
  - Имя автора и дата сообщения
  - Содержание сообщения (с поддержкой форматирования, @mentions, вложений)
  - Индикатор редактирования (если сообщение было отредактировано)
  - Индикатор перевода (если сообщение переведено)
  - Реакции на сообщения
  - Контекстное меню сообщения (Reply, Edit, Delete, Translate, Copy)
  - Вложения: изображения (с preview), файлы (PDF, ZIP, LOG, DOC), видео (с thumbnail и плеером)
  - Ответы на сообщения (ReplyTo) - отображение исходного сообщения

**Правая панель - Свойства тикета:**
- **Assigned Users** - назначенные пользователи (с возможностью добавления/удаления)
- **Tags** - теги тикета (с возможностью добавления/удаления)
- **Priority** - приоритет (выпадающий список)
- **Status** - статус (выпадающий список)
- **Properties:**
  - Source - источник тикета (с иконкой и названием канала)
  - Created - дата создания
  - Последние сообщения (счетчик)
  - Dossier - пользовательский досье (история и вложения)

**Пользовательский Dossier:**
- `dossier_content` - текстовая информация о пользователе
- `dossier_attachments` - вложения (изображения, PDF, другие файлы)

**Dynamic Fields** (отображаются в зависимости от категории):
- **Financial** - Transaction ID (с пометкой AI)
- **Technical** - Environment и Error Logs (с пометкой AI)

**Custom Fields** (из виджета):
- Текстовые поля, email, ссылки
- Возможность копирования значений

#### AI функции:

**AI Smart Draft (`AiDraftPanel`):**
- Генерация ответов на основе базы знаний
- Отображение сгенерированного текста с возможностью применения
- Список источников (документы и тикеты) с превью
- Кнопки: Cancel, Use Response

**AI Context Bar (`AiContextBar`):**
- Отображение источников контекста для AI
- Превью источников при клике
- Ссылки на полные документы/тикеты

**AI Title:**
- Автоматическое название тикета (поле `aiTitle`)

**AI Smart Summary:**
- Автоматическое создание краткого резюме тикета
- Определение текущего состояния тикета
- Анализ тональности (sentiment: positive, neutral, negative)
- Обновление резюме при добавлении новых сообщений

#### Вкладки в деталях тикета:

Тикет разделен на три вкладки:

**1. Public (Публичная переписка)** - основной чат с пользователем:
- Переписка с клиентом
- Отображение всех публичных сообщений
- Индикатор непрочитанных сообщений (красная точка при наличии новых)

**2. Team (Командный чат):**
- Внутренний чат команды для обсуждения тикета
- Сообщения только для админов (не видимы пользователю)
- Индикатор непрочитанных сообщений (счетчик)
- Индикатор набора текста (typing indicator) - кто из команды печатает
- Реакции на сообщения (emoji picker)
- Анимация pulse при появлении новых сообщений на неактивной вкладке

**3. Dossier (Пользовательское досье):**
- Редактируемая информация о пользователе (`dossier_content`)
- История взаимодействий
- Вложения досье (`dossier_attachments`): изображения, PDF, другие файлы
- Режим редактирования (Edit mode) для изменения содержимого
- Загрузка новых файлов в досье

#### Функции работы с сообщениями:

**Отправка сообщений:**
- Текстовое поле ввода с поддержкой форматирования
- Панель инструментов форматирования: Bold, Italic, Heading, Quote, List
- Кнопка отправки (`Send`)
- Вложения через кнопку `Plus` (изображения, файлы, видео)

**Действия с сообщениями:**
- **Reply** - ответ на сообщение (с отображением исходного сообщения)
- **Edit** - редактирование сообщения
- **Delete** - удаление сообщения
- **Translate** - перевод сообщения (с выбором языка перевода)
- **Copy** - копирование содержимого сообщения
- **Forward** - пересылка сообщения

**Перевод сообщений:**
- Выбор языка перевода из списка (10 языков: en, ru, es, de, fr, it, pt, ja, ko, zh)
- Перевод существующих сообщений (выбор сообщения → Translate → выбор языка)
- Переводчик для поля ввода (автоматический перевод перед отправкой)
- Переключение между оригиналом и переводом
- Визуальная индикация переведенных сообщений (флаг языка)

**Парсинг @mentions:**
- Автоматическое распознавание упоминаний в формате `@username`
- Визуальное выделение упоминаний в сообщениях

**Настройки отображения сообщений** (через иконку Settings):
- Показать/скрыть Avatar
- Показать/скрыть Name
- Показать/скрыть Date
- Показать/скрыть Channel
- Показать/скрыть Status
- Показать/скрыть Category

**Макросы (`MacrosMenu`):**
- Доступ к готовым ответам (макросам)
- Фильтрация по категориям макросов
- Применение макроса к сообщению

#### Дополнительные функции:

- **Закрытие тикета** (`CloseTicketDialog`) - диалог с выбором причины закрытия
- **Source Preview** (`SourcePreviewModal`) - предпросмотр исходного сообщения из источника (Discord, Telegram и т.д.)
- **Поиск в переписке** - поиск по содержимому сообщений
- **Фильтрация сообщений** - фильтр по автору, дате, типу
- **Закрепление сообщений** (`Pin`) - закрепление важных сообщений
- Обновление тикета (`RefreshCw`)

## 2. Предложения (Suggestions)

### 2.1. Список предложений (`/suggestions`)

**Назначение:** Управление предложениями от пользователей (Feature Requests).

**Компонент:** `components/admin/SuggestionsListTable.tsx`

#### Отображаемые столбцы таблицы:
- **Checkbox** - выбор строк для массовых действий (скрыт в режиме AI группировки)
- **ID** - идентификатор предложения (в формате `#123`)
- **Subject** - заголовок предложения (кликабельный, ведет к деталям) и краткое описание
- **Author** - автор предложения (username или "System")
- **Category** - категория предложения (с цветовой индикацией)
- **Score** - балл предложения (upvotes - downvotes) с цветовой индикацией
- **Status** - статус (New, Open, Duplicate, Planned, In Progress, Completed, Rejected)
- **Created** - дата создания

#### Режимы отображения:

**Обычный режим:**
- Сортировка по столбцам: ID, Category, Score, Status, Created
- Выбор строк через checkbox
- Пагинация

**AI Grouping режим:**
- Группировка похожих предложений в кластеры
- Мастер-предложение и дочерние предложения
- Разворачивание/сворачивание кластеров
- Объединение кластеров в одно предложение

#### Фильтры:
- **Status Filters** - множественный выбор статусов (синхронизируется с URL параметрами)
- **Category Filters** - множественный выбор категорий
- **Score Filter** - фильтр по баллам (more than / less than значение)
- **Date Filter** - фильтр по дате создания (from/to)
- **Search Query** - текстовый поиск по заголовку и описанию

#### Функции:
- Переход к деталям предложения при клике на строку или заголовок
- **Bulk Actions Bar** (`SuggestionsBulkActionsBar`) - панель действий при выборе строк:
  - Merge - объединение выбранных предложений
  - Set Status - массовое изменение статуса
  - Delete - массовое удаление
- **Filter Chips** (`FilterChips`) - отображение активных фильтров с удалением
- **Filter Dropdown** (`FilterDropdown`) - меню добавления фильтров
- **Settings Modal** (`SuggestionsSettingsModal`) - настройки (только для админов)
- **Create Suggestion** (`CreateSuggestionModal`) - создание нового предложения
  - Модальное окно с полями:
    - Title - заголовок предложения (обязательное)
    - Description - описание предложения (обязательное)
    - Category - выбор категории из списка (обязательное)
    - Is Official - чекбокс для создания официального предложения от команды (только для админов)
  - Для официальных предложений:
    - Автор: "Ninja Product Team" (системный)
    - Статус по умолчанию: "Open" (вместо "New")
    - ID с префиксом "prop-" (вместо "sug-")
    - Автоматически закрепляется (isPinned: true)
  - После создания автоматически переходит к созданному предложению
- **Refresh** - обновление списка
- Переключение AI Grouping режима (в настройках)

### 2.2. Детали предложения (`/suggestions/[id]`)

**Назначение:** Детальный просмотр и управление предложением.

**Компонент:** `components/admin/SuggestionDetail/index.tsx`

**Страницы ошибок:**
- **Error** (`/suggestions/[id]/error.tsx`) - обработка ошибок с кнопками "Back to Suggestions" и "Try again"
- **Not Found** (`/suggestions/[id]/not-found.tsx`) - отображение при отсутствии предложения с кнопкой возврата

**Layout:** Разделен на две панели:
- **Левая панель (275px)** - список предложений (`SuggestionsCardList`)
- **Правая панель** - детали выбранного предложения

#### Отображаемые разделы:

**Заголовок:**
- ID предложения
- Заголовок (title)
- Кнопки действий: Merge, More (Delete, Open in Widget)

**Основной контент:**
- **Оригинальный пост** - первоначальное предложение с автором и датой
- **Вкладки:**
  - **Duplicates** - похожие предложения (AI анализ)
    - Список дубликатов с Match Score, статусом, excerpt
    - Кнопки: Merge (объединение), Upvote/Downvote
  - **Team Chat** - командный чат для обсуждения
    - Список сообщений команды
    - Форма для добавления комментария

**Боковая панель:**
- **Status** - изменение статуса (выпадающий список)
- **Category** - изменение категории (выпадающий список)
- **Metrics:**
  - Score (upvotes - downvotes)
  - Upvotes / Downvotes
  - Views

#### Функции:
- **Merge** (`MergeSuggestionDialog`) - объединение с другим предложением
- **AI Duplicates Analysis** - поиск похожих предложений через AI
- **Discord Preview** (`DiscordPreviewModal`) - предпросмотр как будет выглядеть предложение в Discord
- Изменение статуса и категории
- Комментирование в Team Chat
- Удаление предложения
- Открытие в Widget (для просмотра пользователями)

#### Список предложений (левая панель - `SuggestionsCardList`):

**Компонент элемента списка** (`SuggestionListItem`):
- Аватар автора (или инициалы)
- Badge источника (Discord, Web) с белой обводкой на аватаре
- Заголовок предложения (с переносом строк, до 2 строк)
- Счетчик голосов (ThumbsUp/ThumbsDown) в правом верхнем углу (скрыт для статуса "New")
- Информация об авторе (@username или "Ninja Product Team")
- Относительное время создания (formatRelativeTime)
- Категория (слева внизу, uppercase)
- Статус (справа внизу, с цветной точкой)
- Выделение при выборе (синяя граница слева, светлый фон)

**Функции панели:**
- Карточки предложений с полной информацией
- Фильтрация по статусам
- Поиск по предложениям
- Настройки отображения (показать/скрыть поля)

### 2.3. Настройки предложений (`SuggestionsSettingsModal`)

**Назначение:** Настройка системы предложений.

**Компонент:** `components/admin/SuggestionsSettingsModal/index.tsx`

**Доступ:** Только для пользователей с правами администратора (`hasAdminAccess()`)

#### Вкладки:

**1. Categories:**
- Список категорий предложений
- Создание новой категории (название, цвет)
- Редактирование категории
- Удаление категории

**2. Notifications:**
- Настройка шаблонов уведомлений для каждого статуса
- Редактирование шаблонов сообщений

**3. Banned Users:**
- Список забаненных пользователей
- Поиск по забаненным пользователям (debounced)
- Разбан пользователя (кнопка Unban)
- Lazy loading при переключении на вкладку

#### Функции:
- Сохранение настроек
- Проверка несохраненных изменений при закрытии
- Диалог подтверждения при закрытии с несохраненными изменениями
- Отмена изменений (Reset)

## 3. Категории (Categories)

### 3.1. Список категорий (`/categories`)

**Назначение:** Управление категориями тикетов.

**Компонент:** `components/admin/CategoriesList.tsx`

#### Отображаемые столбцы таблицы:
- **Category Name** - название категории
- **Source Type** - тип источника (Discord, Telegram, Web Widget, Email, API)
- **Created At** - дата создания
- **Updated At** - дата обновления
- **Actions** - действия (редактирование, удаление)

#### Функции:
- Переход к деталям категории при клике на строку
- Создание новой категории
- Редактирование категории
- Удаление категории

### 3.2. Детали категории (`/categories/[id]`)

**Назначение:** Настройка категории тикетов.

**Компонент:** `components/admin/CategoryDetail.tsx`

#### Вкладки настроек:

**1. General (`GeneralTab`):**

*Basic Info:*
- **Category Name** - название категории
- **Description** - внутреннее описание для админов

*Source Type:*
- Выбор типа источника: Discord, Telegram, Web Widget, Email, API
- Отображение бейджа источника

*Access Control:*
- **Has Access** - переключатель доступа к категории

*Ticket Configuration:*
- **Max Open Tickets Per User** - максимальное количество открытых тикетов на одного пользователя
- **Ticket Name Template** - шаблон названия тикета (например, `Bug-{num}`, `Support-{id}`)
- **Priority** - приоритет по умолчанию для тикетов этой категории (low, medium, high)

*Meta (Read-only):*
- Category UUID
- Created At

**2. Form Builder (`FormBuilderTab`):**

*Назначение:* Создание формы для виджета.

- Список полей формы (`FormField[]`)
- Типы полей:
  - Text
  - Email
  - Select (выпадающий список с опциями)
  - Textarea
  - Checkbox
  - Radio
- Для каждого поля:
  - Label - метка поля
  - Placeholder - подсказка
  - Required - обязательность поля
  - Options - опции (для Select, Radio)
- Добавление нового поля
- Удаление поля
- Изменение порядка полей (drag & drop)

*Form Preview:*
- Предпросмотр формы в реальном времени (для Discord и Web Widget)
- Переключение между режимами предпросмотра:
  - **Discord** - как будет выглядеть форма в Discord модальном окне (темный стиль)
  - **Web Widget** - как будет выглядеть форма в веб-виджете (светлый стиль)
- Отображение всех полей с метками, placeholder'ами и индикацией обязательных полей

**3. Integration Settings (`IntegrationSettingsTab`):**

*Динамическое отображение в зависимости от Source Type:*

**Discord Settings** (`DiscordSettings`):
- Настройки интеграции с Discord
- Channel ID
- Webhook URL
- Настройки форматирования сообщений

**Telegram Bot** (`TelegramSettings`):
- Настройки Telegram бота
- Bot Token
- Chat ID
- Настройки команд

**Widget Appearance** (`WebWidgetSettings`):
- Настройки внешнего вида виджета для данной категории
- Цвета
- Иконки
- Тексты

**4. Access Roles (`AccessRolesTab`):**

*Управление доступом:*
- Список ролей системы
- Назначение ролей категории (множественный выбор)
- Удаление роли из категории

#### Функции:
- **Save** - сохранение изменений категории
- **Delete** - удаление категории (с подтверждением)
- Навигация назад к списку категорий

## 4. Макросы (Macros)

**Назначение:** Управление готовыми ответами (макросами) для быстрого ответа в тикетах.

**Компонент:** `components/admin/MacrosList/index.tsx`

## 14. Утилиты и вспомогательные функции

### 14.1. Auth Utils (`utils/auth.ts`)

**Назначение:** Проверка прав доступа пользователей.

**Функции:**
- `hasAdminAccess(userRole?)` - проверка прав администратора
  - Возвращает `true` для ролей: Admin, Manager, Owner
  - По умолчанию проверяет роль "Owner" (мок-данные)

**Типы:**
- `UserRole` - тип роли: 'Admin' | 'Manager' | 'Owner' | 'User'

### 14.2. Current User (`utils/currentUser.ts`)

**Назначение:** Константы текущего пользователя.

**Экспорты:**
- `CURRENT_USER_EMAIL` - email текущего пользователя (временно захардкожено: 'v.panov@dt.team')

**Использование:**
- Для Smart Views в тикетах (Your Inbox, Mentions, Awaiting Reply)
- Определение назначенных тикетов текущему пользователю

### 14.3. KB Folders Utils (`utils/kbFolders.ts`)

**Назначение:** Утилиты для работы с папками базы знаний.

**Функции:**
- `getArticlesInFolder` - получение всех статей в папке (включая вложенные)
- `getFolderArticleCount` - подсчет статей в папке
- `getSubfolders` - получение всех подпапок
- `getDirectSubfoldersCount` - подсчет прямых подпапок
- `getDirectArticlesCount` - подсчет прямых статей (не во вложенных папках)
- `buildFolderTree` - построение древовидной структуры папок

### 14.4. Suggestions Settings API (`utils/suggestionsSettingsApi.ts`)

**Назначение:** API функции для работы с настройками предложений.

**Функции:**
- `fetchSuggestionsSettings()` - загрузка настроек предложений
- `saveSuggestionsSettings(config)` - сохранение настроек
- `fetchBannedUsers(searchQuery?)` - получение списка забаненных пользователей
- `unbanUser(userId)` - разбан пользователя
